# P0：同骨干、自然语言、段落级记忆的可区分性

## 要回答的问题

`docs/沉积式技术评估报告-2026-10-31.md` §9 定的 P0：

> 同骨干场景不需要跨骨干标定，MSP 的 a 臂（1.000）证明记忆层本身够用。
> 唯一没验证的是：**真实自然语言的键，判别性远低于单 token 置换。**
> 若要判断"对话记忆是否有解"，必须用真实粒度重测。

MSP 跨骨干失败的真实机制，是「标定误差夹角 ≈ 类间夹角」（12–15° vs 13.2°，信噪比 ≈1）。
同骨干场景下没有标定误差，但有一个同构的误差源：**同一件事的不同说法**。

所以本实验测的是同一个判据，换了误差源：

```
能否可靠检索  ⇔  同一记忆条目不同说法之间的距离  <  到最近的其他条目之间的距离
```

## 实验设计

### 五组语料

| 组 | 条数 | 域 | 长度 | 控什么变量 |
|---|---|---|---|---|
| G1 跨域 | 30 | 10 个生活领域（饮食/家庭/出行/健康…） | 68 字 | 基线：语义越分散越容易 |
| G2 同域短 | 30 | 全是"某项目的技术方案决定" | 105 字 | 与 G1 比长度、与 G3 比长度 |
| G3 同域长 | 30 | 同 G2 的 30 个项目，扩写 | 241 字 | 与 G2 比：**拉长语义单元是否改善** |
| G4 同项目双维度 | 60 | 30 项目 × 2 个维度 | 101 字 | 最细干扰：项目名相同，只差维度 |
| G5 信息量递减 | 60 | 同 G4，查询侧逐级剥信息 | 14–114 字 | 完整 → 只留结论 → 只剩项目名 |

每条记忆有 3 种说法：正式（结论在前）、口语（闲聊提及）、细节（追问时展开）。
对应"同一个事实在不同场合被复述"——这是真实记忆系统每天的处境。

### 四个指标（逐层计算）

| 指标 | 定义 | 方向 |
|---|---|---|
| `theta_intra_mean` | 同一条目不同说法之间的平均夹角 | 越小越好 |
| `theta_nearest_inter_mean` | 每个向量到**最近**的其他条目的夹角 | 越大越好 |
| `snr` | 上两者之比，**判据 ≥ 2** | 越大越好 |
| `acc_top1` | 变体 0 建库、其余变体查询的 top-1 命中率 | 基线 = 1/N |

> **一个踩过的坑（保留在代码注释里）**：最初用"类中心之间的夹角"当类间距离，得到
> SNR 1.1–2.1 但 top-1 准确率 1.000 的矛盾结果。原因是求中心会把个体差异平均掉，
> 系统性缩小类间夹角。检索关心的是"最容易混淆的那一个"，必须用最近邻。

### 编码设置

- 模型：Qwen3-4B（fp16，7.55 GiB）
- 取 `output_hidden_states`，37 个隐状态（embedding + 36 层）
- 两种池化都测：`mean`（mask 加权）与 `last`（末 token）
- 逐层扫描，报最优层与全曲线

## 已知局限

1. 语料是**模板化合成**的，不是真实对话。真实对话的信息密度更低、指代更含糊，本实验给出的应是**上界**。
2. 只测了 Qwen3-4B 一个骨干，未做 0.83B/9B 的对照。
3. 检索用的是原始 hidden 的余弦相似度，**没有训练任何投影**。训练过的记忆层（MSP 的 key/value 是可学的）能放大判别方向，所以本实验是**下界估计**——但两个"界"都指向同一方向时，结论才可信。
